# Amakuru API

FastAPI modular monolith: identity, tenancy, knowledge governance, retrieval, generation, channels, billing, evaluation and platform ops.

```bash
# from repo root
make setup && make doctor && make dev
# → http://localhost:8000  (OpenAPI at /docs in non-production)
```

Tests: `make test` · Eval: `make eval` · OpenAPI export: `make openapi`.
